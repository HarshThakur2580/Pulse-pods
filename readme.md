# PulsePods

![PulsePods Screenshot](./img/headphone-store.jpg)

## Overview
PulsePods is a **static website** showcasing a premium headphone store. It features a responsive design, smooth scrolling navigation, product listings, customer testimonials, and a contact form.

## Features
- Responsive layout using CSS Flexbox/Grid
- Smooth scrolling navigation with jQuery
- Product showcase with images and price ranges
- Customer testimonials carousel
- Static contact form placeholder

## Tech Stack
- **HTML5**
- **CSS3** (custom styling)
- **JavaScript** (jQuery for smooth scroll)
- **Font Awesome** for icons

## Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/HarshThakur2580/Pulse-pods.git
   ```
2. Open `main.html` in a web browser to view the site.
